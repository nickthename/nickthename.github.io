LabRat is a Smash 64 mod that extends Smash Remix with a variety of features for solo practice, such as:

  • Multiple Savestates
  • Customizable Hotkeys
  • CPU Recording/playback
  • On-screen displays

LabRatは、Smash Remixを拡張したSmash 64の練習用ROMで、1人での練習に役立つさまざまな機能を搭載しています。

  • 複数のセーブステート
  • カスタマイズ可能なホットキー
  • CPU操作の記録・再生
  • 画面上への情報表示
LabRat is still in development. Please report bugs!

Update history

v0.2

  • Integrated controller range display, based on mimi by wemipls
  • Savestates now include spawned items
  • Advanced CPU teching options:
    • Define a sequence for tech chases, such as tech left, then tech right
    • Customize probabilities for random techs
  • Spawn positions can now be set to the ledge
  • CPU recordings can now use looping playback
  • CPU actions can now be recorded frame-by-frame
  • Practice against shield pressure by enabling shield break mode, then recording CPU attacks against your shield
  • Oowait improvements:
    • Now ignores shielding so you can practice OOS timing
    • New visual bar option
    • Appears less frequently and is easier to read
  • Utilt is now available as an OO combo option
  • New player position HUD option
  • More shortcut options
  • Hazard settings can now be customized in-game
  • Various UI updates and bug fixes
